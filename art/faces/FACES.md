# Schiffy's faces (from the user, 2026-11-07)

`schiffy-faces.png` is the official expression sheet for Schiffy: 1536×256, six 256×256 faces left to right.
The user asked for it to be used **wherever it fits across all Schiffy games**.

| # | Face (my reading) | Use for |
|---|---|---|
| 1 | Default: round eyes with two highlights, small brows, pink blush with three lines, brown nose, "w" mouth | idle, menus, portraits |
| 2 | Content / sleepy: eyes closed as soft downward curves | nap, resting, idle blink, cozy moments |
| 3 | Default, small variation | idle variation / blink cycle frame |
| 4 | Default, small variation | idle variation / blink cycle frame |
| 5 | Big joy: eyes closed as "^ ^" arcs, wide "w" smile | win, level up, pickup, celebrate, petted |
| 6 | Surprised / hurt: bigger eyes, raised brows, small round "o" mouth | hit, oops/error, surprise, boss appears |

Shared parts: dark-brown ink (#1e1206-ish), brown nose, pink blush with three dark lines. Keep these exact on every
face so Schiffy looks the same in every game. Faces 3 and 4 look close to face 1 at this size; compare them
side by side before using them as different moods.

How each game applies it is that game's call (texture swap on the head, 2D sprite, UI portrait, Blender
material...). Copy from here; don't redraw by eye. Record what you used in the game's own CLAUDE.md.
